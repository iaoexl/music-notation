# 识谱与乐理拆解指南（music-notation）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个把「乐理、识谱、演奏技巧」拆成可执行动作的开源乐谱知识库：每一篇笔记都拆成 **这是什么 → 为什么这样写 → 怎么看懂 → 怎么弹出来 → 遇到变调/错音怎么办**，读完能直接上手看谱。
> 
> 本仓库不是枯燥的乐理教材搬运工，而是一套**以「能看懂、能弹奏、能写出」为目标的实操手册**。全库分基础识谱笔记、乐理拆解手册、实战扒谱与改编三条线：基础与理论逐块独立成文件，实战技巧拧成完整工作流。

## 使用建议与边界声明

- 内容仅供学习、自我训练与音乐爱好者交流参考，**不构成专业考级绝对标准、不构成商业演出编曲建议或任何艺术流派之争的定论**。
- 涉及不同乐器（如钢琴与吉他）音域与指法解读的部分属于特定场景的适用视角而非绝对事实判定；**识别不出复杂和弦，就不要硬背指法，先看懂构成音**。
- 需说明的是：本仓库全部文件资料由公开乐理书籍、网络开源谱例及个人扒谱整理而来，部分内容经 AI 工具重新归纳、整理与结构化排版。二创或用于商业场景请注明出处，商业使用前请自行确认版权合规（部分原版曲谱需注意版权归属）。
